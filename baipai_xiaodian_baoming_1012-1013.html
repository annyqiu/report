七、口径与规则

  • 消耗口径：报告内所有消耗一律按日均计算（数据窗口 10.12-10.15 共 4 天，日均 = 四日合计 ÷ 4），单位万元/天；所有占比不受影响（分子分母同口径）。
  • 客群判定（永久记忆）：运营三级行业 = 新锐品牌 / 本土传统 / 传统品牌 / 国际品牌 / 国际新锐 → 品牌；其余全部运营三级行业（大货、白牌1、白牌2、大货贸易商、待定、白牌、其他、0、空）→ 白牌；同时含品牌店与白牌店的客户视为混合客群，不并入白牌口径。
  • 有好店 / 无好店：小店好店标类型 = 11（品牌好店）| 12（热销好店）| 13（服务好店）→ 有好店；其余 → 无好店。
  • 双11活动类型：小店商品活动标签 = 1322（金秋大促A类）→ 全资；= 1323（金秋大促B类）→ 混资；其余（空、733官方补贴、1188心智品、736点赞买等）→ 未报满减。
  • 主推店铺：该客户简称下消耗 TOP3 的店铺（按店铺ID聚合，剔除「店铺ID不可见」块）。总消耗取数据源中该简称的汇总行；主推消耗占比 = 主推 TOP3 消耗 / 总消耗。
  • 全资/混资/未报占比：该客户全部店铺行按活动标签归类后的消耗 / 总消耗；同时带 1322 与 1323 的行各计一半，三者相加≈100%。
  • 判定口径（优先级）：好店未报名 → 好店未全资 → 主推未报名 → 类型偏差(无好店却报全资) → 符合。期望动作：有好店 → 好店与主推店铺报全资；无好店 → 主推店铺尽量报混资；无好店却已报全资的客户无需回退、维持现状（类型偏差仅作标记，不作为整改项）。
  • 应报全资消耗= 好店（好店标 11/12/13）店铺的日均消耗合计，即理论上必须报全资的那部分消耗；「占比」= 应报全资消耗 / 该客群总消耗，「已达成」= 已报全资消耗 / 应报全资消耗（消耗维度的全资达成率，与「好店数 / 已报全资」的家数达成率互为补充）。
  • 缺口显著性阈值：单项缺口消耗 ≥ 0.01 万元（100 元）才计入判定，低于阈值视为「符合（可忽略）」，避免长尾零量客户干扰结论。缺口消耗 = 触发该判定的店铺消耗合计。
  • 销售匹配：人户关系表【1 底表（总表）】，A列 short_advertiser_name（简称）优先 → F列 真实客户（=子品牌名称）→ B列 ops_advertiser_name（主体名）兜底。
  • 好店标二次校验（sherry 版好店表）：与「服务好店、热销好店全资商家报名」表（Sherry 维护）按店铺名精确匹配（去空格/括号/符号、忽略大小写；该表「热销标」对应我方 12 热销好店、「服务标」对应 13 服务好店），共补录我方原漏标的 3 家好店（洛希极限臻选、蜜丝李3号店铺、豚鹿八五七美妆店），已直接并入好店数 / 好店类型 / 判定统计，不再单独展示 sherry 版好店标字段；其余命中店铺与 Sherry 标完全一致，无差异。该表是待推进全资报名的好店清单，「不在 Sherry 表」不代表我方标错。
  • Sherry 版好店名单 · 报名进展（模块五）：取自该表全部 264 家好店，已报名 / 未报名 / 未跟进 全部展示，并按客群拆成两块：5.1 白牌客群 42 家（只保留能确认挂在纯白牌客群客户下的店铺，与模块二/三/四/六同为白牌口径，是本报告跟进主体）；5.2 品牌 or 待定客群 222 家（15 家可确认属品牌客群 + 207 家在我方窗口内无记录、客群待定）—— 因 Sherry 版仅有店铺名称、adata 数据以店铺 ID 为主（仅部分记录带店铺名），故只有部分店铺能匹配到我方客群，未匹配者一律归入 5.2、不计入白牌口径。报名进展 = 表内「1016报名进展」列（空值记为「未跟进」）；销售 = 表内「是否建联」列所填对接销售，未填时按「店铺名 → 我方客户简称 → 人户关系表」兜底匹配，仍无则「未匹配」；日均消耗 / 我方好店标 = 该店铺在我方 10.12-10.15 数据中的取值；命中我方名册的店铺一律展示明细（不论窗口内有没有消耗 —— 无消耗显示 0.000，未命中我方名册显示「—」并标注「未命中」）。全表共命中我方名册 57 家（5.1 白牌 42 家、5.2 品牌 15 家），其中窗口内有消耗 39 家、合计日均 11.42 万元；命中家数不按消耗过滤，0 消耗店铺同样计入并展示明细。
