Part 0：报告总览

节点 = 2.1 倍日常：单价不动、单量翻倍；决定一场能做多大的，是有没有报上平台满减。
核心结论
  • 节点 = 2.1 倍日常：34 天占 21.8% 天数，贡献 36.9% 消耗、38.3% GMV；日均 11.24 万 vs 平日 5.36 万，成本 509 vs 503 元。
  • 量来自 eCPM 与拿量：广告数只 +1.4%，eCPM +30%、单条广告拿量 +59%，两者撑起 2.1 倍。
  • 活动决定上限：618 活动期日均 12.15 万、双11 首周 16.04 万；没活动的七夕、中秋、国庆只有 5.85 / 8.16 / 8.92 万。
  • 活动最直接的收益是转化：活动商品下单率 5.00% / 2.90% / 3.96%，三场全面高于非活动的 4.64% / 2.22% / 3.30%。
最大亮点
  • 618 爆发期效率最高：ROI 2.35、成本 420 元（全周期最低）、下单率 4.90%，日均 12.16 万。
  • 双11 首周量价齐升：日均 16.04 万（平日 3.0 倍）、单量 297 单/日、下单率 3.95%（+1.3pt）、单价 1124 元，成本只涨 7.6%。
  • 商品推广效率更高：ROI 2.15 vs 1.91，3s 完播 57% vs 37%，占比 29%。
下一步：双11 剩余 24 天
  • 活动报满：满减 + 大场激励 + 主播分享券三项全报，11.1 / 11.9 / 11.11 三场直播大场单独提报。
  • 供给拉到 900 条/日：618 爆发 985 条做到 ROI 2.35，双11 首周 755 条只有 2.08。
  • 创意优投回 15%：双11 首周只有 3.1%，是六场最低，出价却比 618 爆发高 11%。
  • 出价不追高：守 480-510；6.18 出价 447 元拿到 ROI 2.52，七夕 574 元只有 1.90。
  • 11.11 配量：广告 1200 条、潜客优投 65%、3s 完播 43%。

Part 5：双11 剩余 24 天的活动玩法

设计逻辑双11 首周已经验证两件事——活动商品下单率 3.96%（非活动 3.30%）、单日出量能到 18.83 万。剩下 24 天不换模型，只补三个短板：后段活动热度退潮时把量接住、把 618 爆发那套产品配置搬回来、11.11 的供给提前一天建好。
当前进度平台满减已于 10.12 生效、11.15 截止，现在处在「11.11 抢先购」阶段。越早报满减、越早吃到商品扶持；11.1 与 11.11 两场的提报别等临期。

Part 6：小结与 to do

一句话总结

  • 模型：低客单、高频次，节点靠单量放大，单价基本不动。
  • 量从哪来：eCPM +30% 与单条拿量 +59%，广告数几乎没加——吃的是节点流量红利。
  • 怎么变成能力：活动报满 + 大场前把广告与创意建够 + 补 3 秒钩子。

三个判断

  • 活动决定上限：活动期日均 12-16 万，没活动的节点只有 5.9-8.9 万。
  • 素材供给决定能吃多满：双11 755 条 / 3037 个 → 16.04 万；国庆 367 / 1625 → 8.92 万。
  • 转化效率是活动最直接的收益：活动商品下单率比非活动高 0.36-0.68pt，三场无一例外。
